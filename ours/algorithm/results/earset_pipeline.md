# Full pipeline on EarSet, leave one person out

Generated by `algorithm/scripts/eval_earset.py`. Causal detector (quiet level from the person's still recording) -> head frame (3 calibration nods) -> features -> logistic regression trained on the other 29 people -> gate -> pair rule (1.5 s). Worst-case dictionary: all 6 ordered pairs of different motions among nod/shake/tilt are commands.

6439 detected events in 539 recordings of 30 people.

Event accuracy (axis+signed+timing, before the gate): 0.888

Event accuracy (all incl. magnitude, before the gate): 0.957

## Gate operating points

`head gestures recognised` = share of nod/shake/tilt events that pass the gate with the right name. False rates are per hour of non-gesture recordings (face, talking, chewing, swallowing, walking, running, still; about 7.5 h in total). `FC/h <activity>` = false commands per hour during that activity.
