# Cross-device test: EarSet in-ear prototype <-> AirPods Pro 2

Generated by `phase0/crossdevice.py`. Bouts and features from `build_bouts.py` (EarSet, 30 people, left ear, 2 min continuous per motion) and `airpods.py` (AirPods Pro 2, 4 people, cued 2.5 s takes of double nod / double tilt left+right / idle). Logistic regression, nothing tuned. Frames: R0 sensor axes, R1 gravity, R2 head frame from 3 calibration nods per person (excluded from testing). Features: `all` = 10 features, `axis` = only which-axis-the-head-rotates-about (4 features).

Note the protocols differ too (continuous repetition vs single cued double gestures; EarSet `none` is face and daily-life motion, AirPods `none` is idle takes with talking and looking around).
