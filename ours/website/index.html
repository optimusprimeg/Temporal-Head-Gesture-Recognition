Silent commands from small head motions, read by AirPods

A team member nods, tilts or turns their head in a short two-step pattern. The AirPods' motion sensor picks it up, the phone or Mac recognises the command, and teammates hear it, for example "Alpha 2: enemy left", without anyone speaking or raising a hand.

The idea in one picture

Everything runs on the device, in real time, on a continuous stream. Nobody tells the system when a gesture starts: it has to find the motions itself.

Why it is built this way

Two motions, not one

People nod and turn all day. One motion alone is never a command, so a single everyday movement cannot send one. Commands are built from a few parts, so new commands need no new training data. Commands →

Head frame

Every earbud sits at a different angle in every ear. We rotate the signal into the head's own axes (nod, tilt, turn) using gravity and three calibration nods, so the same motion looks the same for everyone. Features →

Features chosen by statistics

Instead of 96 hand-picked statistics, a mixed model in R measures how much of each feature is "the gesture" and how much is "the person". Only gesture-driven features are trusted across people. R analysis →

Data from a real session

A Mac app records continuous sessions with spoken cues, no-gesture time, walking, re-wearing and two AirPods models, fitted into whatever time a participant has. Data collection →
