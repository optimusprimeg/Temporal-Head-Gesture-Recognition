Independent review: what it confirmed

  • The head frame is built correctly (right-handed, gravity from the half second before each event, nothing from the future), and the detector is causal and handles data gaps.
  • Axis shares and linearity are unit-free and do not depend on event length or sample rate.
  • The R model matches its description; the confidence interval for person + style is bootstrapped as a sum (the correct way); the rule file openly says it was written after seeing EarSet, and the code applies it as written.
  • The Latin square is the standard design; the core repeats on each device (a proper crossover); the live check never forces retakes, so no trial is selected by the classifier.
  • The earlier pipeline's numbers and the EarSet and P01 results quoted in our documents match their source files.

Fixes before the pilot, in order

  1. Fix the loop feature; counterbalance the core; track modules per device; add the pause instruction. Done in app v3 (Mac + iPhone) on 8 Nov.
  2. Freeze all settings before P02 (git tag). P01 stays development data; every trial, including failed ones, stays in the evaluation.
  3. Correct the claims in the code and documents: only the axis shares are R-screened today.
  4. Self-test on P01 with live streaming (data copied to the analysis PC as it is recorded) to settle the pause, the axis-change cut and the walking cues without rebuilding the app for every change.

After the pilot

  • Run the R rule on our own data, over all motions and per direction pair, with ≥ 500 bootstrap draws.
  • Compare all methods on the same splits: old random forest, MiniRocket, DTW, ours.
  • Choose the final motions and the 20 commands from the no-gesture recordings.
  • Build the team hub and the demo; measure end-to-end latency.
  • Covertness test with observers.
